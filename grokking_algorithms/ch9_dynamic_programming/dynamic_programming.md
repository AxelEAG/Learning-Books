Dynammic programming is a problem solving strategy that consists of breaking down 
a problem into discrete subproblems, where you are trying to optimize given a constraint. 
It then solves the subproblems, slowly building up to the final solution.

Every solution involves the use of a grid, where each cell represents the value
that it is trying to optimize.

There's no single formula for calculating a dynamic programming solution, but
generally, asking the following helps:
	* What are the values of the cells?
	* How do you divide this problem into subproblems?
	* What are the axes of the grid?
